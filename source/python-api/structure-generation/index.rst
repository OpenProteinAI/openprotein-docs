Structure Generation
====================

Our platform provides access to structure generation models like BoltzGen (`Stark et al., 2025 <https://hannes-stark.com/assets/boltzgen.pdf>`_) and RFdiffusion (`Watson et al., 2023 <https://www.nature.com/articles/s41586-023-06415-8>`_). These models can be used for workflows like de novo binder design.
