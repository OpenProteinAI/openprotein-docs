This guide will show you how to generate a scanning single-site saturation mutagenesis library for a protein of interest. You will then score the resulting sequences with a protein language foundation model to identify and select promising variants to build an initial mutagenesis library. We recommend using PoET-2 for this task, as it is trained on protein families to learn the rules of evolutionary fitness, and excels in mutation effect prediction zero-shot, without additional property data. However, we also offer other foundation models, like ESM, for this task.
In this how-to, we will be referring to language model scores of protein sequences.

# Before starting
- A protein sequence to analyze.
- A prompt. To learn how to build a prompt, visit [here](/how-tos/dataset/build-a-context)

# Score every substitution

<Tabs items={['App', 'Python']}>
  <Tab value="App">
-     Click the **Tools** dropdown, then click **Substitution**.
- Enter the sequence in the first field.
- Select a model. PoET-2 is recommended for most applications.
- Define the context select an existing prompt, upload an MSA, or enter sequences directly. The prompt sets the context for every score, so build it from sequences related to your protein. 
- Disable the query. 
- Keep refolding settings to `None`
- Click **Run**.

</Callout>

    Load the PoET model and submit the sequence with the prompt. Once the job is complete, the results are returned as a dictionary keyed by variant, such as `b'M1A'`, with one score per prompt in the ensemble. 

    ```
# score every substitution poet = session.embedding.get_model("poet") # load PoET 
sspjob = poet.single_site(prompt=prompt, # submit sequence and prompt 
sequence="MTEYKLVVVGAGGVGKS...".encode()) ssp_results = sspjob.wait() # wait for job to complete 
 ```

# Select variants for the library

<Tabs items={['App', 'Python']}>
  <Tab value="App">
- Review the heatmap. Hover over a cell to see its score. The [highest-scoring] (link to interpreting scores here) variants and sites are listed in the table below the heatmap. 
- Narrow the results to the number of variants you plan to build and test, which is usually set by your assay capacity and budget. We recommend setting **Max Variants** to that number, which keeps the top-scoring variants overall. Here are the filters available: 
   - Max Variants: show the top k variants with the highest PoET-2 scores (recommended)
   - Max Variants per Site: show the top n substitutions at each position.
   - Max Number of Sites: show the top n recommended positions.
   - Limit to Site Number: restrict the results to specific positions, as single values or ranges.
- Click **Export** to download the results as a table.
- Optionally, open the **Input** tab to review the settings used for the run, or click a variant in the heatmap to start a new analysis with the alternate sequence.

<Figure src="/_static/how_to/substitution-analysis/howto-substitution-result.png" />
  </Tab>
  <Tab value="Python">
Average each variant's scores and compare them to the wild type. 

```
# score each variant relative to the wild type 
import numpy as np 
import pandas as pd 
wt = np.mean(ssp_results[b"WT"]) # wild-type score 
scores = pd.DataFrame( 
[(k.decode(), k.decode()[1:-1], np.mean(v) - wt) # variant, site, score 
for k, v in ssp_results.items() if k != b"WT"], columns=["variant", "site", "score"], 
) 
``` 
Apply the same limits as the app filters, then export the shortlist. 
```
# filter and export the shortlist 
library = ( 
scores.sort_values("score", ascending=False) # highest scores first 
.groupby("site").head(2) # Max Variants per Site 
.head(96) # Max Variants 
) 
library.to_csv("library.csv", index=False) 
```
