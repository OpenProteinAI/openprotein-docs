## Protein

[`Protein`](#openprotein.molecules.Protein) is a fundamental primitive for working with proteins on the platform. These can be uploaded to our platform as a [`Query`](/python-api/api-reference/prompt#openprotein.prompt.Query) to be used with models like [`ProteinMPNNModel`](/python-api/api-reference/models#openprotein.models.ProteinMPNNModel) or [`ESMIF1Model`](/python-api/api-reference/models#openprotein.models.ESMIF1Model) (e.g. for inverse-folding), as well as for ease of reuse.

<PyClass path="openprotein.molecules.Protein" />

## Complex

[`Complex`](#openprotein.molecules.Complex) describes a molecular complex representation. These can be uploaded to our platform as a [`Query`](/python-api/api-reference/prompt#openprotein.prompt.Query) to be used with models like [`RFdiffusionModel`](/python-api/api-reference/models#openprotein.models.RFdiffusionModel), (e.g. for multi-chain binder design) as well as for easy reuse.

<PyClass path="openprotein.molecules.Complex" />

## Structure

[`Structure`](#openprotein.molecules.Structure) describes a collection of [`Complex`](#Complex) instances. These are typically created when parsing structure files (e.g., CIF, PDB) that contain multiple models of the same molecular complex, such as NMR ensembles or computational predictions with multiple conformations.

<PyClass path="openprotein.molecules.Structure" />

## Ligand

[`Ligand`](#openprotein.molecules.Ligand) represents a ligand that can be described either by ``smiles`` or ``ccd``. These are intended to be used as part of a [`Complex`](#Complex).

<PyClass path="openprotein.molecules.Ligand" />

## DNA

[`DNA`](#openprotein.molecules.DNA) represents a DNA chain. These are intended to be used as part of a [`Complex`](#Complex).

<PyClass path="openprotein.molecules.DNA" />

## RNA

[`RNA`](#openprotein.molecules.RNA) represents a RNA chain. These are intended to be used as part of a [`Complex`](#Complex).

<PyClass path="openprotein.molecules.RNA" />

## Template

[`Template`](#openprotein.molecules.Template) describes a template that can be used for constraining fold jobs.
