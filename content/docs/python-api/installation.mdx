You can install the package via [pip](https://pypi.org/project/openprotein-python/) or [conda](https://anaconda.org/openprotein/openprotein-python/files) as below:

## pip

```bash
pip install openprotein-python
```

## conda

```bash
conda install -c openprotein openprotein-python
```

**Source code**

The source code is available at [https://github.com/OpenProteinAI/openprotein-python](https://github.com/OpenProteinAI/openprotein-python).
