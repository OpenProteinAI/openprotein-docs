By the end you'll have an MSA saved in your project, ready to build a prompt. An MSA lines up related protein sequences so that shared positions sit in the same column; PoET learns those patterns and generates new sequences that fit the family.

## Before starting

- An OpenProtein.AI  project. If you don't have one, create it first by following the [Quickstart guide](/quickstart).
- [TEM-1](https://drive.google.com/uc?export=download\&id=1jiYbzCLpDbI3xHmndR6oTK7hECswjihv) MSA file in .fasta format. This tutorial uses an MSA of TEM-1 beta-lactamase and its homologs.
- The wild-type seed sequence, ready to paste. This tutorial uses TEM-1:
  `MSIQHFRVALIPFFAAFCLPVFAHPETLVKVKDAEDQLGARVGYIELDLNSGKILESFRPEERFPMMSTFKVLLCGAVLSRVDAGQEQLGRRIHYSQNDLVEYSPVTEKHLTDGMTVRELCSAAITMSDNTAANLLLTTIGGPKELTAFLHNMGDHVTRLDRWEPELNEAIPNDERDTTMPAAMATTLRKLLTGELLTLASRQQLIDWMEADKVAGPLLRSALPAGWFIADKSGAGERGSRGIIAALGPDGKPSRIVVIYTTGSQATMDERNRQIAEIGASLIKHW`

TEM-1 is a small, well-studied beta-lactamase and the reference member of a large protein family, which makes it a clear worked example.

## Upload an MSA

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    - Open your project.
    - Start the upload from either place:
      - On the project page, click Upload, then select MSA.
      - In the left sidebar, click Upload under MSA.
    - Enter the alignment directly, or choose your .fa, .fasta, or .csv file.

    <Figure src="/_static/tutorials/dataset/msa/upload-msa.png" />
    <Figure src="/_static/tutorials/dataset/msa/msa-preview.png" />

    When the upload finishes, the MSA opens in a preview table: one row per sequence, one column per aligned position. Your MSA is now saved in the project and ready to use.

    <Figure src="/_static/tutorials/dataset/msa/msa-table.png" />
  </Tab>
  <Tab value="Python">
    Upload a `.fasta`, `.fa`, or `.csv` alignment file. `get_msa()` returns the aligned sequences so you can confirm the upload.

    ```py lineNumbers
    with open("tem1_msa.fasta", "rb") as f:
        msa = session.align.upload_msa(f.read())

    list(msa.get_msa())
    ```
  </Tab>
</Tabs>

## Build an MSA from a seed sequence

If you don't have an alignment yet, build one from a single sequence. A homology search takes one seed sequence, finds related sequences in public databases such as UniProt, and aligns them for you.

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    - Open your project.
    - Start from either place:
    - On the project page, click **Upload**, then select **MSA**.
      - In the left sidebar, click **Upload** under **MSA**.
      - Enter a single sequence as the seed. Use the TEM-1 sequence from What you'll need.
    - Click **Search for homologs to build MSA**.
    - Wait for the search to finish.

    <Figure src="/_static/tutorials/dataset/msa/single-seq-paste.png" />

    The finished MSA appears in your project, for example under Use Existing MSA when you build a prompt.

    <Figure src="/_static/tutorials/dataset/msa/single-seq-results.png" />

    You can also run the search while building a prompt: open the prompt **Context**, choose **Build From MSA**, then **Run Homology Search Using a Seed Sequence**. If you enter several sequences, only the first is used.

    <Figure src="/_static/tutorials/dataset/msa/single-seq-tool.png" />
  </Tab>
  <Tab value="Python">
    Pass the seed sequence to create_msa. The call runs the homology search; wait() blocks until it finishes, then get_msa() returns the alignment.

    ```py lineNumbers
    msa = session.align.create_msa(seed.encode())
    msa.wait()
    list(msa.get_msa())
    ```
  </Tab>
</Tabs>

## What we did

We learned how to create a multiple sequence alignment on the platform. It can be done by uploading an existing MSA or creating a new one using homology search with a seed sequence.
