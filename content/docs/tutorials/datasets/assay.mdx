## About the dataset
Wrenbeck et al. (2017) measured the fitness of single-substitution variants of AmiE grown on three amide substrates: acetamide, propionamide, and isobutyramide. Fitness is normalized so that the wild type scores 0. Negative values mark variants less fit than the wild type, and positive values mark fitter variants.

The csv file holds 6,819 rows. 6,478 rows are single substitutions at positions 1 to 341 of the 346-residue protein. The remaining 341 rows carry the wild-type sequence, each with a fitness of 0 on all three substrates.


**Wild-type sequence**

Every variant differs from the 346-residue wild-type AmiE sequence at one position:
`MRHGDISSSNDTVGVAVVNYKMPRLHTAAEVLDNARKIAEMIVGMKQGLPGMDLVVFPEYSLQGIMYDPAEMMETAVAIPGEETEIFSRACRKANVWGVFSLTGERHEEHPRKAPYNTLVLIDNNGEIVQKYRKIIPWCPIEGWYPGGQTYVSEGPKGMKISLIICDDGNYPEIWRDCAMKGAELIVRCQGYMYPAKDQQVMMAKAMAWANNCYVAVANAAGFDGVYSYFGHSAIIGFDGRTLGECGEEEMGIQYAQLSLSQIRDARANDQSQNHLFKILHRGYSGLQASGDGDRGLAECPFEFYRTWVTDAEKARENVERLTRSTTGVAQCPVGRLPYEGLEKEA`

Mutation codes name each change against this sequence: wild-type residue, position, new residue. For example, `M1W` replaces the methionine at position 1 with tryptophan, and `H3V` replaces the histidine at position 3 with valine.
The wild type is the baseline for the fitness scores, which is why its score is 0. In Step 6, we set it as the reference sequence so the table shows each variant's mutation code.

### Set the wild type as the reference sequence

  <Tab value='App'>

<Figure src="/_static/tutorials/dataset/upload-assay/dataset-set-reference-sequence.png" />


The wild-type sequence pins to the top of the table, and two columns appear. Mutant shows each variant's mutation code, such as `M1W`, and No. of Mutations shows 1 for every substitution.
Open Table Settings. Under Sequence View Options, select Mutations only to show only the residues that differ from the wild type, or Full sequence to show every residue.

<Figure src="/_static/tutorials/dataset/upload-assay/dataset-set-reference-sequence.png" />

To enter the reference by hand instead, open **Table Settings**, select **Set Reference Sequence**, and paste the wild-type sequence.
  </Tab>
  <Tab value='Python'>
    The reference sequence is a table view setting in the app. In Python, we build the same Mutant and No. of Mutations columns from the wild-type sequence with pandas.

```py lineNumbers
wild_type = dataset["sequence"].iloc[3] 

def mutation_code(sequence):
    changes = [
        f"{wt}{position}{new}"
        for position, (wt, new) in enumerate(zip(wild_type, sequence), start=1)
        if wt != new
    ]
    return "; ".join(changes) or "(same)"

dataset["mutant"] = dataset["sequence"].map(mutation_code)
dataset["n_mutations"] = dataset["sequence"].map(
    lambda sequence: sum(wt != new for wt, new in zip(wild_type, sequence))
)
dataset[["mutant", "n_mutations"]].head()
```
Across the file, 6,478 rows have 1 mutation and the 341 wild-type rows have 0.

### View sequence space using UMAP 

<Tabs items={['App', 'Python']}>
  <Tab value='App'>
In the **View** menu, select **UMAP**.

Each point is one sequence variant in the dataset. The UMAP job starts during upload, so the view shows a waiting message until the job finishes. Switch between properties to change colors in the UMAP.

<Figure src="/_static/tutorials/dataset/upload-assay/dataset-umap.png" />

  </Tab>
  <Tab value='Python'>
    `fit_umap` embeds the dataset's sequences with a protein language model, then reduces them to two dimensions.

```py lineNumbers
import numpy as np

model = session.embedding.get_model("prot-seq")
umap_model = session.umap.fit_umap(model=model, reduction="MEAN", assay=assay)
umap_model.wait_until_done(verbose=True)

coords = {seq.decode(): xy for seq, xy in umap_model.embeddings}
xy = np.vstack(dataset["sequence"].map(coords))

plt.scatter(xy[:, 0], xy[:, 1], c=dataset["acetamide_normalized_fitness"], s=3)
plt.colorbar(label="acetamide_normalized_fitness")
plt.show()
```

`umap_model.embeddings` returns each fitted sequence with its 2D coordinates. Mapping them back by sequence puts the points in the same order as dataset, so each point can be colored by a property.
    
  </Tab>
</Tabs>
