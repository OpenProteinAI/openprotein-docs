In this tutorial, we will use a trained custom model to predict antigen binding for a batch of antibody sequences. We will prepare paired heavy- and light-chain inputs, select the predictor, compare predicted values and uncertainties, and export the results.

We will continue from [Train a specialized property predictor using your data](/tutorials/learn/training-property-predictors), using the “ANT Binding Predictor - PoET-2” model trained on the Makowski 2022 Fab dataset. This model predicts normalized binding to HGFR, the target antigen of emibetuzumab.

Unlike zero-shot scoring, these predictions use a model trained on experimental measurements uploaded by the user. The predictor maps foundation model embeddings to the property measured in the training assay.

## Before starting

- Complete **Train a specialized property predictor using your data** and have the trained **ANT Binding Predictor - PoET-2** model available.

- Have the [Makowski Fab dataset CSV](/_static/data/makowski2022_fab.csv) used in that tutorial. We will submit the first five sequences from this dataset for property prediction by the trained predictor.

## Prepare the antibody sequences

The training dataset contains separate **heavy** and **light** columns representing VH and VL in the Fab antibody. We will preserve the pairing between them and keep the heavy chain first, matching the model’s training configuration. Represent each pair as:

```text
VH_SEQUENCE:VL_SEQUENCE
```

The colon separates the chains. Do not submit the heavy and light chains as independent examples. Note that if the predictor was trained on single-domain sequences and we want to perform batch analysis on similar single-domain sequences, then each sequence can be represented as a simple string of amino acids, without requiring the colon chain separator.

## Run Batch Analysis

We will submit all five antibody pairs together. The predictor will return a property estimate and uncertainty for each pair.

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    <Steps>
      <Step>
        On the Batch Analysis setup page, under **Step 1: Input Sequences**, click select a file to upload  makowski_fab_batch.fasta.
      </Step>
      <Step>
        At the top of the page, click the pencil in the name bar to name your job `ANT Binding Prediction - PoET-2`, so that you can find it easily later.
      </Step>
      <Step>
        Click **Run**.
      </Step>
    </Steps>
  </Tab>
  <Tab value="Python">
    Submit the sequences:

    ```python lineNumbers
    predict_job = predictor.predict(sequences=sequences)
    print("Prediction job ID:", predict_job.job_id)
    means, variances = predict_job.wait(verbose=True)
    ```

    The API returns predicted means and **variances**. We will convert the variances to standard deviations when building the results table.
  </Tab>
</Tabs>

## Inspect the predictions

We will examine:

- **Predicted mean:** The model’s estimate of normalized antigen binding.

- **Predicted standard deviation:** The uncertainty associated with that estimate.

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    <Steps>

      </Step>
      <Step>
        Sort the **Mean** column from highest to lowest. Do this either by clicking the down arrow button in the “Mean” column header, or from the right panel by clicking the “**+**” button in the “Filters” section, and selecting to sort by log-likelihood score.
      </Step>

  </Tab>
  <Tab value="Python">
    Build a results table while retaining the mapping to the original heavy–light pairs:

    ```python lineNumbers
    import numpy as np

    predicted_sequences = [
      sequence.decode() if isinstance(sequence, bytes) else sequence
      for sequence in predict_job.sequences
    ]
    predicted_means = np.asarray(means)[:, property_index]
    predicted_variances = np.asarray(variances)[:, property_index]

    results = pd.DataFrame({
      "sequence": predicted_sequences,
      "predicted_mean": predicted_means,
      "predicted_std": np.sqrt(predicted_variances),
    })
    predictions = results.merge(
      batch[["name", "heavy", "light", "sequence"]],
      on="sequence",
      how="left",
      validate="one_to_one",
    )
    assert len(predictions) == 5
    assert predictions["name"].notna().all()

    print(
      predictions[["name", "predicted_mean", "predicted_std"]]
      .to_string(index=False)
    )
    ```

    Expect five rows, one for each antibody pair. The numerical values will come from the completed job.

    Sort the results:

    ```python lineNumbers
    predictions = predictions.sort_values(
      "predicted_mean",
      ascending=False,
    )
    print(
      predictions[["name", "predicted_mean", "predicted_std"]]
      .to_string(index=False)
    )
    ```

    The Makowski dataset also contains ova, a measure of binding to ovalbumin used as a surrogate for nonspecific binding. Our ANT predictor does **not** predict this property. A high predicted ANT value alone therefore does not establish improved specificity. To evaluate both objectives, we would train a separate OVA predictor and consider high antigen binding alongside low nonspecific binding.

## Export the results

We will retain the paired sequences, predicted values, and uncertainties together.

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    Select **Export as CSV** to download the results table.
  </Tab>
  <Tab value="Python">
    Save the predictions:

    ```python lineNumbers
    predictions.to_csv(
      "makowski_fab_ant_predictions.csv",
      index=False,
    )
    ```

    Record the model, property, and prediction job:

    ```python lineNumbers
    import json
    run_details = {
      "predictor_id": str(predictor.id),
      "property": property_name,
      "prediction_job_id": str(predict_job.job_id),
    }
    Path("makowski_fab_batch_run.json").write_text(
      json.dumps(run_details, indent=2)
    )
    ```
