We’ll look at the results in three ways:
Prediction scores for each variant
A table with the predicted mean and standard deviation for the properties you select
A heatmap showing the effect of each substitution at each position
Finally, we’ll apply a filter to narrow the list down to the variants you want to keep.

**Before starting** 

A trained property predictor that was fine-tuned on an [experimental dataset](https://docs.google.com/spreadsheets/d/1e9VfxiYPFIq2JpSCEBAS03_SgFaqd69yL5TA48VY8d8/edit?usp=sharing). For this tutorial, we will use an antibody dataset from [Makowski et al. 2022](https://doi.org/10.1038/s41467-022-31457-3). If a model has not been trained yet, follow the model training documentation [link to model training](/tutorials/learn/training-property-predictors).
One starting protein sequence to enumerate single substitutions and score.

**Step 5: Read the results**

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    In the table, each substitution is reported with a predicted mean and standard deviation for the selected property. The standard deviation quantifies the uncertainty of the prediction: a higher value indicates greater uncertainty in the predicted mean.

    In the heatmap, hover over a point to view the log-likelihood score for that substitution variant. The higher, or less negative, the log-likelihood score, the fitter the variant.

    Each color in the heatmap shows how a mutation to the corresponding residue at that site would affect fitness compared to the input sequence:

    Blue: improved fitness.

    Red: reduced fitness.

    A site that is all white: a mutation at that site would not affect fitness.
    In the panel on the right, find the heatmap view settings and the property targets. 
  </Tab>
  <Tab value="Python">
    Results come back as arrays aligned with sspredict.sequences. Index [0] holds the mean and [1] holds the variance; .T[0] selects the first property column. Pair them per variant:

    ```py lineNumbers
    from collections import namedtuple

    Score = namedtuple("Score", ["sequence", "mean", "var"])
    [Score(s, mu.item(), var.item())
     for s, mu, var in zip(sspredict.sequences[:5], ssp_results[0].T[0][:5], ssp_results[1].T[0][:5])]
    ```

    The mean and variance values above are illustrative, taken from the reference example. Standard deviation is the square root of the variance. Sequences are returned as bytes, so .decode() them for readable labels.
  </Tab>
</Tabs>

**Step 7: Narrow the list with a filter**

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    The filters cut the results down to the substitutions you care about.

    Set Max Variants to 50. 

    This should filter the number of sequences in the table down to 50. The corresponding sequences will be highlighted in the heatmap.
  </Tab>
  <Tab value="Python">
    Build a table and take the top 50 by predicted mean:

    ```py lineNumbers
    import numpy as np
    import pandas as pd

    mean = ssp_results[0].T[0]
    var = ssp_results[1].T[0]

    df = pd.DataFrame({
      "sequence": [s.decode() for s in sspredict.sequences],
      "mean": mean,
      "stdev": np.sqrt(var),
    })

    top50 = df.sort_values("mean", ascending=False).head(50)
    top50.to_csv("top50_variants.csv", index=False)
    ```
  </Tab>
</Tabs>
