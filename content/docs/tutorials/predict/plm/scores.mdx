In this tutorial, we will use PoET-2 to score the relative fitness of a small set of protein variants without training a model on experimental measurements. This is **zero-shot scoring**: the foundation model evaluates sequences using patterns learned during pretraining and the examples supplied in its context.

We will score Lipase A (EstA) from Bacillus subtilis, comparing the wild-type sequence with two single-substitution variants and their combination. We will use the same context for all four sequences, rank the results, and compare each variant with the wild type.

## Before starting

- Have an EstA context prepared using [Tutorial: Building a prompt context](/tutorials/learn/in-context-learning). For other ways to prepare a context, refer to [How to create a prompt context](/how-tos/dataset/build-a-context).

- **Python client:** Have an authenticated OpenProtein.AI session, with numpy and pandas installed.

We will use the following variants:

1. EstA_WT: Wildtype EstA sequence

2. EstA_R33A: Wildtype EstA sequence with arginine to alanine substitution at position 33

3. EstA_L84R: Wildtype EstA sequence with leucine to arginine substitution at position 84

4. EstA_R33A_L84R: Wildtype EstA sequence with both substitutions in (2) and (3)

## Run the scoring job

We will submit all four sequences together. Scoring evaluates the supplied sequences; it does not generate new variants.

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    Click **Run** and wait for the scoring job to complete. Runtime typically takes several minutes and depends on sequence length, context size, ensemble count, and service load.
  </Tab>
  <Tab value="Python">
    Submit the sequences to PoET-2:

    ```python lineNumbers
    score_job = session.embedding.poet2.score(
        sequences=[sequence.encode() for sequence in sequences],
        prompt=context,
    )

    print("Job ID:", score_job.job_id)

    score_job.wait_until_done(verbose=True)
    results = list(score_job.get())

    print("Returned sequences and scores:", len(results))
    ```

    Expected output after successful completion:

    ```text
    Returned sequences and scores: 4
    ```

    Refer to the [PoET-2 scoring API reference](https://docs.openprotein.ai/python-api/api-reference/embedding.html#openprotein.embeddings.PoET2Model.score) for the scoring arguments.
  </Tab>
</Tabs>

## Rank the sequences

We will compare the log-likelihood scores. A **higher, or less negative, score** indicates that the model considers a sequence to have higher fitness and compatibility with the supplied context. These scores help prioritize variants based on evolutionary fitness, which are generally correlated with properties of interest such as enzyme activity, stability, or expression.

    Build a table of sequence scores, and sort them in descending order of score magnitude. If the context contains multiple replicates, we will use the mean of the returned replicate scores:

    ```python lineNumbers
    import numpy as np
    import pandas as pd

    name_by_sequence = dict(zip(sequences, names))
    records = []

    for result in results:
        sequence = result.sequence
        if isinstance(sequence, bytes):
            sequence = sequence.decode()

        records.append({
            "name": name_by_sequence[sequence],
            "sequence": sequence,
            "score": float(np.asarray(result.score).mean()),
        })

    scores = pd.DataFrame(records)
    scores = scores.sort_values("score", ascending=False)

    print(scores[["name", "score"]].to_string(index=False))
    ```

## Compare each variant with the wild type

We will calculate a relative score by subtracting the wild-type score:

**Relative score = variant score − wild-type score**

- **Positive:** The variant scores higher than the wild type.

- **Negative:** The variant scores lower than the wild type.

- **Zero:** The scores are equal.

Keep comparisons within the same model, context, and scoring configuration. Scores from different prompts should not be treated as directly interchangeable.

<Tabs items={['App', 'Python']}>
  <Tab value="App">
    Compare each variant’s score with **EstA_WT** – in this example, this was submitted as the first sequence to be scored. Export the table to add a column to calculate the differences in a spreadsheet. The wild type sequence should have a relative score of **0**.
  </Tab>
  <Tab value="Python">
    Add a column containing the relative scores:

    ```python lineNumbers
    wt_score = scores.loc[
        scores["name"] == "EstA_WT",
        "score",
    ].iloc[0]

    scores["relative_score"] = scores["score"] - wt_score

    print(
        scores[["name", "score", "relative_score"]]
        .to_string(index=False)
    )
    ```
