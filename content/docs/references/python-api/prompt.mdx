Create prompts and queries for [PoET models](/references/python-api/models#openprotein.models.PoET). The Models interface accepts a prompt ID, a compatibility `Prompt`, a stored Data `Prompt`, or a Data `PromptFuture` as `prompt=` (or `None`). If you already have a stored alignment, see [sample a prompt from a stored MSA](/references/python-api/data#alignments-and-sampled-prompts).

```python
msa = session.align.create_msa("ACDEFGHIK")
prompt = msa.sample_prompt(num_sequences=10)
job = session.models.poet.embed(["ACDEFGHIK"], prompt=prompt)
```

Some pinned SDK docstrings still link to the deprecated embedding interface.
