This compatibility interface is deprecated. Use [`session.models`](/references/python-api/models) for model access.

Train property predictors from your datasets to enable predictions for new sequences! Use crossvalidation on the trained predictors to estimate uncertainty. Trained predictors can be used to design new sequences based on design goals for properties.
