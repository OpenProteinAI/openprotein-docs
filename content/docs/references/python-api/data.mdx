Upload your dataset to OpenProtein.AI's engineering platform for train, predict and design tasks. `session.data.Assay.create()` takes a pandas DataFrame with a `sequence` column. Measurement columns hold properties for training; identify free-text columns separately as metadata.

This example uses an [authenticated session](/references/python-api/openprotein#session).

```python
import pandas as pd

table = pd.DataFrame({
    "sequence": ["ACDE", "ACDF"],
    "activity": [1.2, 0.8],
    "notes": ["first", "second"],
})
assay = session.data.Assay.create(table, name="Example", metadata_columns=["notes"])
```

See the [assay upload guide](/how-tos/dataset/upload-assay) for more detail.

[`session.data.MSA`](#openprotein.data.DataAPI.MSA) and [`session.data.Prompt`](#openprotein.data.DataAPI.Prompt) are resource classes bound to your session. Use `create()` to upload a file, `list(limit=...)` to browse your resources, and the class with `id=...` to load an existing resource. Omitting `limit` reads every page.

Start a homology search through [`session.align`](/references/python-api/align), load its stored MSA, and sample a prompt. You can submit sampling while the search is running. PoET accepts the prompt handle while sampling is still running.

```python
sequence = b"MKTAYIAKQRQISFVKSHFSRQLEERLGLIEVQAPILSRVGDGTQDNLSGAEK"
search = session.align.create_msa(sequence)
msa = session.data.MSA(id=search.id)
prompt = msa.sample_prompt(replicates=2, max_msa_sequences=10, seed=42)
job = session.models.poet.embed([sequence], prompt=prompt)
print(job.id)
```

`wait()` returns the ready handle. Index or iterate it to load its content. An MSA yields `(name, sequence)` pairs; a prompt yields one list of sequences per replicate. A failed or canceled job raises `JobFailedException` when you call `wait()` or `get()`. Uploaded resources are ready immediately and have no job ID.

```python
msa.wait(timeout=600)
print(msa[0])
for replicate in prompt.wait(timeout=600):
    print(replicate[:3])
```

**See also**

- Use [`session.align`](/references/python-api/align) to build an alignment. If you already have the file, [`session.data.MSA.create()`](#openprotein.data.MSA.create) replaces the deprecated [`session.align.upload_msa()`](/references/python-api/align#openprotein.align.AlignAPI.upload_msa).
- [`session.data.Prompt.create()`](#openprotein.data.Prompt.create) uploads prompt data as one FASTA file per replicate. Use [`session.prompt.create_prompt()`](/references/python-api/prompt#openprotein.prompt.PromptAPI.create_prompt) to build a prompt from Python sequences, `Protein` objects, or `Complex` objects.
