## Session management

After [installing the SDK](/quickstart#installation), authenticate with the username and password for your OpenProtein.AI account. [`openprotein.connect()`](/references/python-api/openprotein#openprotein.connect) looks up each credential in this order:

1. **Function arguments:** `username` and `password` passed to `openprotein.connect()`.
2. **Environment variables:** `OPENPROTEIN_USERNAME` and `OPENPROTEIN_PASSWORD` set in the environment where you run Python.
3. **Configuration file:** `~/.openprotein/config.toml` in your home directory.

Use environment variables or a configuration file to keep credentials out of scripts and notebooks. To use a configuration file, create the `.openprotein` folder in your home directory and save this as `config.toml`, replacing the placeholders with your credentials:

```toml
username = "your_username"
password = "your_password"
```

The file stores your password in plain text. Keep it private and out of version control.

Once you've set the environment variables or created the file, connect without passing credentials:

```python
import openprotein

session = openprotein.connect()
```

If authentication fails, check your credentials and whether environment variables are overriding the file. Use the `session` to [run your first model](/references/python-api/models#interface). Full reference: [`openprotein`](/references/python-api/openprotein).
