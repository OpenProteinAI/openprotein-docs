## List models

[`session.models.list_models()`](#openprotein.models.ModelsAPI.list_models) lists the system models available on the platform. By default it returns model IDs (`list[str]`). Set `verbose=True` for [model cards](#openprotein.models.ModelMetadata), which include display names and supported methods. Use `path` to filter by method; `path=["embeddings"]` matches models with an embedding method.

```python
model_ids = session.models.list_models()
print(model_ids[:5])

cards = session.models.list_models(verbose=True, path=["embeddings"])
for card in cards[:5]:
    print(card.model_id, card.name)
```

System model listings exclude your fitted models. Use [`session.models.GP.list()`](#openprotein.models.GP.list), [`session.models.SVD.list()`](#openprotein.models.SVD.list), or [`session.models.UMAP.list()`](#openprotein.models.UMAP.list) to list your fitted models by family. Since SDK 0.18.1, these methods return up to 100 fitted models by default and warn when a default call returns 100. Pass `limit=None` to read every page from `offset`, or set an explicit `limit` to cap the total. Set `offset` to skip results.

```python
fitted_gps = session.models.GP.list(limit=100)
print([gp.id for gp in fitted_gps])
if len(fitted_gps) == 100:
    next_gps = session.models.GP.list(limit=100, offset=100)
```

<PyGroup id="poet-2" title="PoET-2" level={3}
  anchors={[
    "openprotein.models.PoET2",
  ]}
>

OpenProtein-developed conditional and multi-modal protein language model that embeds, scores, and generates sequences conditioned on an input protein family.

*[Understanding protein function with a multimodal retrieval-augmented foundation model](https://www.doi.org/10.52202/085713-1772)* · [GitHub](https://github.com/OpenProteinAI/PoET-2)

The `PoET2` class below is the interface for `poet-2`. It supports sequence tasks and fitting downstream models.

| Model ID | Accessors | Interface |
| --- | --- | --- |
| `poet-2` | [`poet2`](#openprotein.models.ModelsAPI.poet2), [`poet_2`](#openprotein.models.ModelsAPI.poet_2) (alias of `poet2`) | [`PoET2`](#openprotein.models.PoET2) |

```python
from openprotein.molecules import Protein

model = session.models.poet2
msa = session.align.create_msa("MKTAYIAKQRQISFVKSHFSRQ")
prompt = msa.sample_prompt(num_sequences=10)
backbone = Protein.from_filepath("backbone.cif", chain_id="A")

job = model.embed(["MKTAYIAKQRQISFVKSHFSRQ"], reduction="MEAN", prompt=prompt)
embeddings = job.wait()
print(embeddings[0].shape)

job = model.logits(["MKTAYIAKQRQISFVKSHFSRQ"], prompt=prompt)
logits = job.wait()
print(logits[0].shape)

job = model.attn(["MKTAYIAKQRQISFVKSHFSRQ"], prompt=prompt)
attention = job.wait()
print(attention[0].shape)

job = model.score(["MKTAYIAKQRQISFVKSHFSRQ"], prompt=prompt)
log_likelihoods = job.wait()
print(log_likelihoods[0])

job = model.single_site("MKTAYIAKQRQISFVKSHFSRQ", prompt=prompt)
substitution_scores = job.wait()
print(substitution_scores[0])

job = model.indel("MKTAYIAKQRQISFVKSHFSRQ", insert="A", prompt=prompt)
indel_scores = job.wait()
print(indel_scores[0])

job = model.generate(prompt=prompt, query=backbone)
sequences = job.wait()
print(sequences[0])
```

## Task results

Model methods return futures for their submitted tasks. See [how to read task results](/references/python-api/jobs#task-results) or [read a fitted model](/references/python-api/jobs#fitted-model-results).

For a specialized task future with per-position result type `T`, `get()` and `wait()` return `list[T]`. `get_item()` and unit reads return one `T`; `stream()` yields results in order. Bare reads select the task's primary output. Use `get(output=...)` or `wait(output=...)` to select a named output, which has its own result type.

| Future | Primary output | Type per position |
| --- | --- | --- |
| [`EmbeddingFuture`](/references/python-api/jobs#openprotein.jobs.EmbeddingFuture) | `embeddings` | `numpy.ndarray` |
| [`LogitsFuture`](/references/python-api/jobs#openprotein.jobs.LogitsFuture) | `logits` | `numpy.ndarray` |
| [`AttentionFuture`](/references/python-api/jobs#openprotein.jobs.AttentionFuture) | `attn` | `numpy.ndarray` |
| [`LogLikelihoodFuture`](/references/python-api/jobs#openprotein.jobs.LogLikelihoodFuture) | `loglikelihood` | `float`, `list[float]`, or `numpy.ndarray` |
| [`SingleSiteScoreFuture`](/references/python-api/jobs#openprotein.jobs.SingleSiteScoreFuture) | `score` | `float`, `list[float]`, or `numpy.ndarray` |

Use `session.models.SVD`, `session.models.UMAP` and `session.models.GP` to create estimators. Their fitting methods return fit futures. Call `get()` or `wait()` on the fit future to retrieve the fitted model, or select `output=...` to read a named fit output. See [fitted-model results](/references/python-api/jobs#fitted-model-results) for fit and cross-validation futures. Inspect the fitted model card for its advertised methods.

Replace `your-assay-id` with the ID of an existing [assay dataset](/references/python-api/data). All three estimators fit on the same embeddings job for the assay's sequences. Set `new_sequences` to the sequences you want to transform or predict on after fitting. For the UMAP example, use an assay with more than five distinct sequences.

```python
assay = session.data.Assay(id="your-assay-id")
embedding_job = session.models.esm2.embed(assay, reduction="MEAN")
new_sequences = ["ACDEFGHIK", "ACDEYGHIK"]
```

**SVD: project onto two components**

```python
svd_fit = session.models.SVD(n_components=2).fit(embedding_job)
svd = svd_fit.wait()
projections = svd.transform(new_sequences).wait()
print(projections[0].shape)
```

**UMAP: map sequences into two dimensions**

```python
umap_fit = session.models.UMAP(n_components=2, n_neighbors=5).fit(embedding_job)
umap = umap_fit.wait()
coordinates = umap.transform(new_sequences).wait()
print(coordinates[0].shape)  # (2,)
```

**GP: predict a measured property**

Replace `activity` with the name of a measurement column in the training assay that contains observed values.

```python
measurement = "activity"
gp_fit = session.models.GP(kernel="rbf").fit(embedding_job, property=measurement)
gp = gp_fit.wait()
predictions = gp.predict(new_sequences).wait()
first_prediction = predictions[0][measurement]
print(first_prediction["mean"], first_prediction["variance"])
```

Fitted GP models expose their [trained kernel](/references/python-api/models#openprotein.models.TrainedKernel), prior mean and observation noise variance. The mean uses the trained property units; noise uses those units squared. Hyperparameters are unavailable for GPs trained before they were recorded. The compatibility predictor also does not expose them for ensembles.
