This compatibility interface is deprecated. Use [`session.models`](/references/python-api/models) for model access.

Create PDBs of your protein sequences via our folding models! Note that for Boltz and AlphaFold2 Models, you will also need to utilize our [align](/references/python-api/align) workflow to create MSAs.
