---

## **Job list**

Each row shows one job. Fields appear left to right in this order.

| Field | Description |
| :---- | :---- |
| Status | Icon showing the job outcome. A green check means the job succeeded. A red cross means it failed. |
| Name | The job name set when the job was created. Jobs run without a name show the full job ID instead. |
| Short ID | First 7 characters of the job ID, with a copy button that copies the ID. |
| Job type | The tool and operation that ran, marked with a colored dot per type. |
| Project | The project the job belongs to, with a folder icon. Blank for jobs not linked to a project. |
| Model | The model used, shown as a colored badge. Blank for jobs that do not use a model. |
| Created | Date and time the job was submitted. |
| Job menu (⋮) | Actions for a single job. |

**Toolbar**

The toolbar above the job list narrows, orders, and exports jobs. Filters combine, and an active filter shows a count badge with the number of values selected.

| Control | Description |
| :---- | :---- |
| Search | Finds jobs by name or job ID. |
| Project | Shows jobs from the selected projects. |
| Type | Shows jobs of the selected job types. |
| Model | Shows jobs that used the selected models. |
| Status | Shows jobs with the selected status. |
| Created | Shows jobs created within the selected date range. |
| Clear filters (X) | Removes all active filters. Appears only when a filter is applied. |
| Sort | Orders the job list. Newest first by default. |
| Export | Downloads the jobs in the current view. |
