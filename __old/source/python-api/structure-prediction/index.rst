Structure Prediction
=====================

Our Python API provides access to open source models for structural prediction - including ESMFold2, which predicts full biomolecular complexes (multiple protein chains, nucleic acids, and ligands), and AlphaFold2 (`Jumper et al., 2021 <https://www.nature.com/articles/s41586-021-03819-2>`_). Use these structure prediction models to derive meaningful representations of your protein sequence.
